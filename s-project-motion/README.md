# S-PROJECT — Logo motion

Готовая HTML/SVG-анимация появления логотипа по предоставленному референсу. Длительность **2,5 секунды**. Кадр **1920 × 1080**, видео **30 fps**. Минималистичная геометрия без вращения, свечения, отскоков и непрерывного движения в финале.

## Готовые файлы

Для использования заставки не нужно устанавливать инструменты разработки:

- [`exports/s-project.mp4`](exports/s-project.mp4) — светлый фон, H.264.
- [`exports/s-project-dark.mp4`](exports/s-project-dark.mp4) — тёмный фон, белый логотип.
- [`exports/s-project-transparent.webm`](exports/s-project-transparent.webm) — прозрачный фон, VP9 с альфа-каналом.
- [`exports/s-project-final.png`](exports/s-project-final.png) — финальный светлый кадр.
- [`exports/s-project-final-dark.png`](exports/s-project-final-dark.png) — финальный тёмный кадр.
- [`exports/s-project-final-transparent.png`](exports/s-project-final-transparent.png) — финальный PNG с прозрачностью.
- [`assets/logo.svg`](assets/logo.svg) — самостоятельный SVG исходного векторного логотипа.
- `exports/s-project.svg`, `exports/s-project-dark.svg`, `exports/s-project-transparent.svg` — финальные SVG с соответствующим фоном.

**MP4 не имеет прозрачности.** Для наложения анимации на видео используйте WebM VP9 с альфа-каналом, а для статичной графики — прозрачный PNG. Не все проигрыватели и видеоредакторы поддерживают альфа-канал WebM: некоторые показывают чёрный фон даже при наличии прозрачности. Прозрачный PNG позволяет отдельно проверить результат.

## Просмотр проекта

Нужен Node.js 20 или новее. В терминале, из папки проекта:

```sh
cd s-project-motion
npm start
```

Откройте `http://127.0.0.1:4173` в браузере. Сервер использует только стандартную библиотеку Node.js; для просмотра `npm install` не требуется. Вся графика и анимация находятся локально, внешние библиотеки и CDN во время воспроизведения не загружаются.

Управление расположено **вне экспортируемого кадра**:

- Автоматический однократный запуск после загрузки.
- **Повторить** — Replay с самого начала.
- **Пауза / Воспроизвести** — остановка и продолжение.
- **В начало** — остановка и возврат на 0 секунд.
- **Цикл** — повторное воспроизведение.
- **Скорость** — 0,5× / 1× / 1,5× / 2×.
- Ползунок — точный просмотр выбранного времени; перемещение ставит воспроизведение на паузу.
- **Фон** — светлый, тёмный или прозрачный. Шахматная подложка — только обозначение прозрачности в предпросмотре, в экспорт она не попадает.
- **PNG / SVG** — настоящий экспорт финального кадра с выбранным фоном прямо из браузера.
- **MP4 / WebM** — скачивание приложенных готовых видео. Это фиксированные экспорты, скорость предпросмотра их не изменяет.

После финальной фиксации логотип остаётся неподвижным. Остановка сервера — Ctrl+C. Для другого порта можно задать переменную `PORT`.

## Геометрия и шрифт

Сохранены **10 лучей и 10 конечных точек**. Все лучи исходят из `(203, 205)` в координатах референса. Концы лучей: `(278,85)`, `(210,102)`, `(126,147)`, `(71,204)`, `(165,220)`, `(152,267)`, `(204,303)`, `(252,314)`, `(246,225)`, `(250,183)`. Точки имеют радиус `7,1`, линии — толщину `3,6`. Асимметрия и относительные длины сохранены; координаты восстановлены вручную по растровому изображению, поэтому точность ограничена его разрешением.

Центральный узел радиусом `1,8` совпадает с пересечением линий. В финале он не расширяет исходный силуэт пересечения.

**Замена шрифта:** оригинальная гарнитура не предоставлена. Использована **Roboto Regular, weight 400, width 90** — вариант с более узкими пропорциями, подобранный под референс. Надпись переведена в SVG-контуры: на устройстве зрителя шрифт не требуется, буквы не заменяются и не смещаются после загрузки. Видимая область надписи в координатах референса: `x=338…650`, `y=178…225,03`. Это приближение к исходному начертанию, а не подтверждение оригинальной гарнитуры.

Лицензия шрифта: [`assets/Roboto-OFL.txt`](assets/Roboto-OFL.txt), SIL Open Font License 1.1. Статический экземпляр шрифта сохранён в `assets/Roboto-Regular.ttf` для дальнейшего редактирования; во время воспроизведения он не загружается. Источник: [Google Fonts / Roboto](https://github.com/google/fonts/tree/main/ofl/roboto).

Весь логотип имеет один постоянный композиционный transform: `translate(103.2 61.2) scale(2.4)`. Он расположен по центру кадра с сохранением соотношения размеров знака и текста. Появление текста не меняет положение знака или всей композиции.

## Временная шкала

| Время, секунды | Событие |
| --- | --- |
| 0,00–0,20 | Центральный узел: opacity 0→1, scale 0,85→1 |
| 0,20–1,10 | Лучи от центра: stroke-dashoffset 1→0, задержка 18 мс между лучами |
| 1,10–1,40 | Конечные точки: opacity 0→1, scale 0,85→1, задержка 8 мс |
| 1,40–2,10 | Надпись целиком: opacity 0→1, сдвиг вправо 8 px→0 |
| 2,10–2,50 | Полностью статичная финальная композиция |

Для лучей используется `cubic-bezier(0.45,0,0.25,1)`, для текста — `cubic-bezier(0.22,1,0.36,1)`, для узла и точек — ease-out. Единственная временная шкала в `animation.js` управляет предпросмотром, перемоткой и покадровым экспортом. В коде нет случайных величин или независимых CSS-анимаций.

## Повторяемый экспорт видео

Нужны:

1. Node.js 20+.
2. Chrome или Chromium.
3. FFmpeg с кодеками `libx264` и `libvpx-vp9`.

Установите зависимости с зафиксированным lockfile:

```sh
npm ci
npm run export
```

Экспортёр автоматически запускает временный локальный HTTP-сервер, открывает Chromium через Playwright Core, устанавливает размер кадра 1920×1080 и снимает **75 PNG-кадров** на времени `n/30`. FFmpeg собирает из них видео. Финальные PNG/SVG экспортируются на времени 2,5 с. Временный сервер закрывается, промежуточные кадры удаляются. Вручную запускать `npm start` перед экспортом не нужно.

Команда по умолчанию создаёт все перечисленные файлы в `exports/`. Размер кадра, fps и длительность фиксированы по заданию; выбранные настройки предпросмотра их не меняют.

Отдельные варианты:

```sh
npm run export -- --theme light --format mp4
npm run export -- --theme dark --format mp4
npm run export -- --theme transparent --format webm
npm run export -- --theme transparent --format png
npm run export -- --theme light --format svg
```

Доступные `--theme`: `all`, `light`, `dark`, `transparent`. Доступные `--format`: `all`, `mp4`, `webm`, `png`, `svg`. Сочетание `transparent` + `mp4` отклоняется с объяснением, чтобы не создавать ложную прозрачность.

Если браузер не найден автоматически, задайте путь:

```sh
CHROME_PATH=/полный/путь/к/chromium npm run export
```

В PowerShell:

```powershell
$env:CHROME_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
npm run export
```

Браузер по умолчанию ищется в стандартных путях Linux, macOS и Windows. В этой среде экспорт проверен с Node.js 24, Chromium 154, FFmpeg 7.1.5 и Playwright Core 1.62.1. Экспорт требует этих внешних инструментов; кнопки PNG/SVG в обычном браузере не требуют FFmpeg или Playwright.

## Проверки

```sh
npm ci
npm test
```

11 браузерных проверок проверяют геометрию, все пять фаз, монотонный рост лучей, отсутствие overshoot, детерминированную перемотку, неподвижный финальный кадр, autoplay/Replay/паузу/сброс/цикл/скорость, фон, фактическую прозрачность захватываемого кадра, настоящие PNG/SVG-загрузки и адаптивную композицию на ширинах 375, 768 и 1920 px. Скриншот интерфейса записывается в `test-results/interface.png` (не включается в исходники).

Проверить параметры готового видео:

```sh
ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=width,height,r_frame_rate,nb_read_frames:format=duration exports/s-project.mp4
```

Для чтения альфа-канала WebM используйте декодер **libvpx-vp9**: стандартный встроенный декодер FFmpeg может его не возвращать.

```sh
ffmpeg -c:v libvpx-vp9 -i exports/s-project-transparent.webm -ss 2.4 -vf alphaextract -frames:v 1 alpha.png
```

```text
tests/animation.test.mjs   функциональные проверки в браузере

```
