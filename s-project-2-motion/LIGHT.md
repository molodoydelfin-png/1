# S-PROJECT — белая прозрачная версия

Пять секунд, 1920×1080, 30 кадров/с, 150 кадров.

## Скачать и использовать

- **`exports/s-project-2-light-alpha.mov`** — основной файл для монтажа: **ProRes 4444 с альфа-каналом**, светлый знак и белая надпись. Положите его на дорожку поверх своего фона или видео. Внутри также есть тихая звуковая дорожка PCM stereo.
- **`exports/s-project-2-light-alpha.webm`** — компактная версия **VP9 с настоящим альфа-каналом** и звуком Opus. Подходит для браузера и редакторов с поддержкой WebM alpha.
- **`exports/s-project-2-light-preview.mp4`** — **только предпросмотр на тёмном фоне**, со звуком AAC. Этот MP4 непрозрачный, фон в него записан намеренно для удобного просмотра белого логотипа.
- **`exports/s-project-2-light-final.png`** — чистый белый финальный логотип, PNG RGBA, прозрачный фон.

Некоторые проигрыватели показывают чёрный фон даже у прозрачного файла. Проверяйте прозрачность наложением на другой цвет или видео в редакторе. Если программа не поддерживает альфа-канал WebM, используйте MOV ProRes 4444. Альфа хранится без фоновой цветовой заливки; прозрачность проверена после декодирования, а не только по метаданным.

В WebM контейнер может показывать 5,008 с из-за служебной задержки Opus. Сам видеоряд содержит ровно 150 кадров при 30 fps. У MOV и MP4 длительность 5,000 с.

## Что изменилось в движении

Знак не вращается как цельная картинка. Направления всех десяти лучей остаются исходными, а их длина меняется бегущей по окружности волной. Удлинение с одной стороны и укорочение с другой создают ощущение вращения. Сферы сохраняют круглую форму и движутся по своим лучам. В конце волна затухает, все длины возвращаются к оригинальным.

В тексте используются силуэты **оригинальной S, дефиса и PROJECT**, включая надрезы из загруженного PNG. Гарнитура не подменяется. Поверх них проходит узкий световой фронт: сначала светятся контуры, затем за лучом остаётся чистая белая форма. Восемь маленьких фрагментов исходных контуров кратко отделяются от краёв, смещаются и исчезают. После 3,7 с остаётся статичная чистая композиция без луча и фрагментов.

Светлый знак выполнен в той же гамме: белые лучи и мягкие перламутровые сферы с исходным направлением освещения. Это цветовая версия исходного знака, а не новые буквы или новая геометрия.

## Повторить экспорт

Из папки проекта с установленными зависимостями из `requirements.txt`:

```sh
python scripts/render_light.py
python tests/check_light.py
```

Нужны Python 3.11+ и FFmpeg с `libvpx-vp9`, `libopus`, `prores_ks`, `libx264` и AAC. Подготовленная дорожка `assets/sound-design.wav` используется без изменений. Рендерер создаёт промежуточные PNG RGBA в `.cache/light-frames/`, затем собирает три файла. Эта временная папка исключена из Git. Все движения и фрагменты детерминированы.

Проверка WebM alpha вручную — с декодером libvpx-vp9:

```sh
ffmpeg -c:v libvpx-vp9 -i exports/s-project-2-light-alpha.webm -ss 4.5 -vf alphaextract -frames:v 1 alpha.png
```

Проверки также подтверждают перемещение волны по всем десяти направлениям, наличие сфер на фактических промежуточных кадрах, сохранение исходной типографики, отсутствие фоновой заливки, исчезновение временных эффектов, неподвижный финал и реальный альфа-канал обоих прозрачных видео.
