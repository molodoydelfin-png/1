# S-PROJECT — чистое раскрытие без пружины

Пять секунд, 30 кадров/с. Белая надпись, светлый знак, прозрачный фон. Свет раскрывает текст из середины надписи в обе стороны.

## Готовые файлы

- **`exports/s-project-2-clean-preview.mp4`** — качественный предпросмотр Full HD 1920×1080 на тёмном фоне. MP4 непрозрачный, для наложения используйте файлы ниже.
- **`exports/s-project-2-clean-4k-preview.mp4`** — нативный предпросмотр 3840×2160 на тёмном фоне.
- **`exports/s-project-2-clean-alpha.mov`** — ProRes 4444, 1920×1080, настоящий альфа-канал, звук PCM. Основной совместимый файл для видеоредактора.
- **`exports/s-project-2-clean-alpha.webm`** — VP9 lossless alpha, 1920×1080, звук Opus.
- **`exports/s-project-2-clean-4k-alpha.webm`** — нативный мастер **3840×2160**, VP9 lossless alpha. Это новый рендер кривых и геометрии в 4K, а не растянутое Full HD видео.
- **`exports/s-project-2-clean-final.png`**, **`exports/s-project-2-clean-4k-final.png`** — прозрачные финальные PNG.
- **`exports/s-project-2-clean-final.svg`**, **`exports/s-project-2-clean-4k-final.svg`** — векторная финальная композиция.

Прозрачность каждого видео проверяется после декодирования. Простой проигрыватель может показать чёрный фон у MOV или WebM: при наложении на другую дорожку в поддерживающем формате редакторе фон прозрачный.

## Что исправлено

Все лучи теперь движутся только наружу и плавно останавливаются. Нет волны длины, обратного движения, overshoot или пружинящих колебаний. Сохраняются десять исходных направлений, конечные положения и измеренные размеры сфер. Небольшие задержки связаны с длиной луча, а не с обходом по кругу.

Растровые фрагменты шариков и лучей больше не растягиваются. Линии и круги строятся по измеренной геометрии отдельно, с общей непрерывной связью. Суперсэмплинг геометрии — 8× для Full HD и 4× для 4K. Уменьшение идёт усреднением площади: фильтр не создаёт боковых ореолов и отлетающих полупрозрачных точек.

Контуры исходных S и PROJECT обведены в кубические кривые SVG, очищены от однопиксельной ступенчатости и рендерятся Cairo с 4× суперсэмплингом. Новый шрифт не подставляется: исходная форма и надрезы сохраняются. Очистка чуть меняет субпиксельный край; проверка сравнивает геометрию с исходником, а не обещает побайтовое равенство старому растровому контуру.

Световое раскрытие от центра, белый цвет и финальная пауза сохранены. Отделяющихся частиц нет. Качество кодирования предпросмотра повышено; у WebM альфа и видеоряд кодируются VP9 lossless.

## Пересобрать

Из папки проекта, Python 3.11+, FFmpeg с VP9 alpha, ProRes 4444 и H.264, а также системная библиотека Cairo:

```sh
python -m pip install -r requirements.txt
python scripts/render_clean.py
python scripts/render_clean.py --4k
python tests/check_clean.py
```

`assets/wordmark-clean.svg` содержит кривые букв. Если он уже есть, для рендера не нужно повторять трассировку. Временные кадры сохраняются в `.cache/s-project-2-clean-frames/` и `.cache/s-project-2-clean-4k-frames/` и не входят в Git. Предыдущие заставки сохранены отдельными файлами для сравнения.

Проверки контролируют монотонность каждого луча, отсутствие отдельных точек во всех ранних кадрах и в декодированных видео, соответствие букв исходнику, сохранение надрезов, нативные 4K-размеры, реальную прозрачность и неподвижный финал. В WebM длительность контейнера может показывать дополнительные 8 мс из-за задержки Opus; сам видеоряд — ровно 150 кадров при 30 fps.
