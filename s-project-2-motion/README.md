# S-PROJECT 2.0 — появление логотипа

**Белая версия с более спокойной волной лучей, световым раскрытием текста от центра и прозрачным фоном:** [файлы и инструкция](LIGHT.md). Для наложения используйте `s-project-2-light-center-alpha.mov` или `s-project-2-light-center-alpha.webm`; MP4 этой версии служит предпросмотром на тёмном фоне.

Готовая пятисекундная заставка для команды технического обеспечения мероприятий S-PROJECT. Обновлённая версия: одновременное радиальное раскрытие знака и мягкое проявление надписи.

## Готовые материалы

- **`exports/s-project-2-radial.mp4`** — обновлённая версия со звуком; 1920×1080, 30 fps, 150 кадров, 5 секунд; H.264 + AAC stereo.
- **`exports/s-project-2-radial-silent.mp4`** — обновлённое видео без звука, без повторного сжатия видеопотока.
- **`exports/s-project-2-final.png`** — финальный кадр без потерь.
- **`assets/sound-design.wav`** — отдельная звуковая дорожка, 48 kHz, stereo, 16 bit, 5 секунд.
- **`assets/source.png`** — точная копия загруженного исходного изображения «Минималистичный логотип S-PROJECT.png».
- **`exports/render-info.json`** — размеры, координаты, параметры кадрирования и SHA-256 исходника.

Откройте MP4 в видеопроигрывателе. Для просмотра обеих версий в браузере можно открыть `preview.html` и нажать Play; элементы управления не входят в само видео.

## Сохранение оригинального логотипа

Используются **пиксели загруженного PNG**. Ни буква S, ни PROJECT, ни дефис, ни сферы не набираются заново и не генерируются. Знак раскрывается единым радиальным движением от своего центра, с сохранением асимметрии. Лучи и сферы движутся вместе. S мягко проявляется целиком; дефис и PROJECT также проявляются одной целой группой. Прорисовки по штрихам, угловой очередности лучей, горизонтальных шторок и выезда букв нет.

Для движущихся слоёв выделены только тёмные пиксели исходника: светлые фрагменты фоновых прямоугольников и секторов не перемещаются вместе со знаком. В конце плавно восстанавливается исходная светлая фактура фона.

На исходном изображении измерены десять конечных сфер и общий центр `(389, 526)`. Направления и относительные длины лучей остаются исходными. Деликатный объём сфер и букв взят из исходника, без добавления хрома или новых бликов.

Источник имеет соотношение сторон 4:3: **1448×1086**. Для требуемого 16:9 применяется одно равномерное масштабирование **1920/1448** и обрезка свободного поля сверху и снизу. Окно исходника: `x=0…1448`, `y=112,25…926,75`. Логотип целиком остаётся в кадре. Презентационная подпись **«Вариант A»**, расположенная под логотипом в загруженном файле, находится за границами этого окна.

Финальный PNG побайтово совпадает по RGB-пикселям с результатом такого единого преобразования исходника. В финальной паузе кадры рендерера неизменны. MP4 сохраняет ту же геометрию и композицию; обычное сжатие H.264 с потерями может немного менять значения отдельных пикселей.

## Сценарий

| Время | Действие |
| --- | --- |
| 0–0,35 с | Маленький центральный узел |
| 0,35–2,25 с | Все десять лучей вместе со сферами расходятся из центра: лёгкий выход примерно на 4,2% за конечный размер, мягкое обратное движение и фиксация. Без вращения |
| 2,15–3,3 с | Оригинальная S проявляется целиком через плавную прозрачность |
| 2,3–3,55 с | Дефис и PROJECT проявляются вместе, без движения и шторок |
| 3,2–3,7 с | Деликатная финальная доводка исходной фоновой фактуры |
| 3,7–5 с | Полностью неподвижный оригинальный логотип |

Звуки созданы синтезом: короткий тихий низкочастотный импульс, мягкие механические щелчки и затухающий тон завершения. Сторонняя музыка и звуковые библиотеки не использованы. Дорожка намеренно тихая, пик около −27 dBFS.

## Повторяемый рендер

Нужны Python 3.11+ и FFmpeg с `libx264` и AAC. В этой среде проверено с Python 3.12 и FFmpeg 7.1.5.

Из папки `s-project-2-motion`:

```sh
python -m venv .venv
```

Активируйте окружение: `source .venv/bin/activate` в Linux/macOS или `.venv\Scripts\activate` в Windows. Затем:

```sh
python -m pip install -r requirements.txt
python scripts/render.py
python tests/check_animation.py
```

Рендерер передаёт 150 RGB-кадров в FFmpeg, добавляет звук и записывает файлы в `exports/`. Промежуточные кадры не занимают диск. Все движения детерминированы, шум в звуковых эффектах использует фиксированное зерно. Повторный запуск обновляет только экспортируемые материалы и звуковую дорожку.

Привязки рассчитаны на приложенный исходник: другой PNG с другими размерами не будет автоматически растянут или подменён.

## Проверки

`tests/check_animation.py` проверяет центры десяти сфер по самому PNG, одновременное радиальное раскрытие, реальное наличие всех десяти сфер и лучей на раннем кадре, сдержанную пружину с возвратом в исходный размер, цельное появление текста, отсутствие светлых фоновых пикселей в подвижном слое, чистое начальное поле, точное совпадение финального PNG с исходником после кадрирования, отсутствие скачка в конце, неподвижную финальную паузу, повторяемость, WAV и параметры MP4.
